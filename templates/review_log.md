# Review log — __SLUG__

One entry per round: snapshot the film, `npm run render && npm run review`,
then two fresh critic subagents score the round from contact.png, phone.png,
report.md (motion checks first) and flags.png. A row's score for the round is
the lower of the two. The film ships when no row is under 8.

Rows: stop (point by 2 s) · read (360 px) · change (no idle stretch) ·
moves (beats, springs) · layout · brand · sound.

Issues are marked P0 (breaks a house rule, or can't be read), P1 or P2; P0s
are fixed first. Several formats: one table per format, or a Format column.

# Tally (example brand)

A fictional brand so the kit works out of the box: `npm run new -- my-film --brand example`.
Nothing here describes a real product. Copy `brands/_blank` for your own brand.

- `brand.json` — voice, proof rules, CTA, colour roles
- `brand.css` — Tally's tokens and the `--film-*` roles every film reads
- `index.tsx` — `fonts`, `LogoMark`, `Logotype`
- `fonts/` — Geist and Geist Mono by Vercel, SIL Open Font License 1.1 (`fonts/OFL.txt`)
